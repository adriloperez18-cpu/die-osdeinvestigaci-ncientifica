# InvestigaLab · Blog de Diseños de Investigación

Blog académico sobre diseños de investigación cuantitativa, cualitativa y mixta.
Autor: Adrián López Pérez · Metodología de la Investigación.

Sitio estático de una sola página (`index.html`), sin dependencias que instalar.
Solo carga las tipografías desde Google Fonts, por lo que necesita conexión a internet para verse con su estilo completo.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `blog-investigalab`), público.
2. Sube a la raíz del repositorio los archivos `index.html`, `.nojekyll` y este `README.md`.
3. En el repositorio ve a **Settings → Pages**.
4. En **Build and deployment → Source** elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera uno o dos minutos. El blog quedará en:

   `https://TU-USUARIO.github.io/blog-investigalab/`

## Actualizar el contenido

Edita `index.html` en el repositorio (botón del lápiz en GitHub) y guarda con **Commit changes**. GitHub Pages republica el sitio automáticamente.
